# 🤖 بوت حضور Google Meet الصامت التلقائي (Google Meet Silent Attendance Bot)

مشروع بايثون متكامل ومحسّن لحضور حصص واجتماعات Google Meet تلقائياً في وضع الخفاء التام (**Headless Mode**)، مصمم خصيصاً للعمل بكفاءة وثبات داخل خوادم سحابية ذات موارد محدودة جداً (**512MB RAM** مثل بيئة **Render Free Tier** أو **Railway**).

---

## ⚡ الميزات والتقنيات الأساسية

1. **تحسين الذاكرة الفائق (Ultra-low Memory Footprint < 300MB RAM)**:
   - **Route Abort**: حظر كامل لتحميل الصور (`png`, `jpg`, `webp`, إلخ)، خطوط الويب (`woff`, `woff2`, `ttf`)، ملفات الميديا، تدفقات الفيديو، وروابط التتبع والتحليلات.
   - **Chromium Flags**: تعطيل التسريع الرسومي (`--disable-gpu`)، إيقاف مشاركة الذاكرة المؤقتة لبيئات الدوكر (`--disable-dev-shm-usage`)، تقييد مساحة محرك جافاسكريبت (`--js-flags=--max-old-space-size=256`)، وكتم الصوت نهائياً لمنع أي معالجة صوتية.
   - **صغر مساحة العرض (Viewport 800x600)**: لتقليل استهلاك معالجة وتصيير عناصر الصفحة (DOM Rendering).

2. **الانضمام الذكي كضيف (Guest Join)**:
   - حقن اسم الطالب تلقائياً في خانة الاسم.
   - كتم المايكروفون وإغلاق الكاميرا تلقائياً عبر الأذونات الوهمية (`--use-fake-ui-for-media-stream`) والاختصارات (`Ctrl+D`, `Ctrl+E`).
   - التعرف المرن على أزرار الانضمام (`طلب الانضمام` / `Ask to join` / `Join now`) باللغتين العربية والإنجليزية.

3. **مراقبة الشات والرد التلقائي (Chat Monitor & Auto-Reply)**:
   - مراقبة رسائل الشات بشكل دوري وخفيف على المعالج (`asyncio.sleep`).
   - في حال رصد اسم الطالب أو أي من الكلمات المفتاحية المحددة، يقوم البوت بكتابة رسالة اعتذار مسبقة وإرسالها فوراً في الشات.
   - مزود بنظام **Cooldown** (فترة تهدئة قابلة للتعديل) لمنع تكرار الرسائل وتجنب الإزعاج (Anti-spam).

4. **تتبع استهلاك الذاكرة (Memory Logging)**:
   - مراقبة دورية لاستهلاك الرام الفعلي للعملية والنظام وطباعته في سجلات التشغيل (Logs).

## ⚙️ متغيرات البيئة (Environment Variables)

| المتغير | الوصف | القيمة الافتراضية / مثال |
|---|---|---|
| `MEET_URL` | رابط حصة أو اجتماع Google Meet (مطلوب) | `https://meet.google.com/abc-defg-hij` |
| `STUDENT_NAME` | اسم الطالب المعروض في الحصة | `أحمد علي` |
| `AUTO_REPLY_MESSAGE` | رسالة الرد التلقائي عند المناداة | `عذراً أستاذ، المايك معطل لدي اليوم وأنا حاضر ومتابع معكم في الحصة.` |
| `TRIGGER_KEYWORDS` | كلمات مفتاحية إضافية لرصدها بالشات (مفصولة بفاصلة) | `أحمد,يا أحمد,احمد,طالب` |
| `AUTO_REPLY_COOLDOWN_SECONDS` | الفاصل الزمني بالثواني بين الردود التلقائية | `300` (5 دقائق) |
| `MAX_DURATION_MINUTES` | الحد الأقصى لبقاء البوت بالحصة بالدقائق | `90` |
| `HEADLESS` | التشغيل الصامت بدون واجهة رسومية | `1` (سحابياً) أو `0` (محلياً للمعاينة) |
| `BROWSER_LOCALE` | لغة واجهة المتصفح | `ar` أو `en` |

## 🚀 التشغيل السريع محلياً (Local Testing)

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. تجهيز ملف الإعدادات:
قم بنسخ ملف `.env.example` إلى `.env` وضع رابط الحصة الخاص بك:
```bash
cp .env.example .env
```

### 3. تشغيل البوت:
```bash
python bot.py
```

> **نصيحة للمعاينة المحلية**: يمكنك ضبط `HEADLESS=0` في ملف `.env` لمشاهدة المتصفح وهو يفتح الرابط ويكتب الاسم ويكتم المايك وينضم خطوة بخطوة.

## ☁️ النشر على خادم Render (512MB RAM)

منصة **Render** تتيح تشغيل Docker Containers مجاناً:

### الطريقة الأولى: عبر ملف `render.yaml` (Blueprints):
1. ارفع هذا المجلد إلى مستودع على GitHub (خاص أو عام).
2. في لوحة تحكم Render، اضغط **New +** ثم اختر **Blueprint**.
3. اربط مستودع GitHub، وسيقوم Render تلقائياً باكتشاف ملف `render.yaml` وإنشاء **Background Worker**.
4. أضف متغير البيئة `MEET_URL` في إعدادات البيئة واضغط حفظ.

### الطريقة الثانية: كخدمة Background Worker يدوية:
1. اختر **New +** -> **Background Worker**.
2. اختر **Docker** كبيئة التشغيل.
3. في إعدادات الخطة اختر **Free** (512MB RAM).
4. في قسم **Environment Variables**، أضف المتغيرات المذكورة في الجدول أعلاه.
5. اضغط **Deploy**.

## 🐳 التشغيل بواسطة Docker محلياً أو على أي سيرفر VPS

```bash
# بناء الصورة
docker build -t meet-bot .

# تشغيل الحاوية وتمرير المتغيرات
docker run -d --name my-meet-bot \
  -e MEET_URL="https://meet.google.com/abc-defg-hij" \
  -e STUDENT_NAME="أحمد علي" \
  meet-bot

# متابعة السجلات واستهلاك الرام
docker logs -f my-meet-bot
```

## ⚠️ ملاحظات هامة حول قيود Google Meet:
- **دخول الضيوف (Guest Access)**: يعتمد الانضمام كضيف بدون تسجيل دخول Google على إعدادات الاجتماع لدى المعلم أو المنظم (أن يكون الاجتماع متاحاً للعموم أو يطلب الانضمام). إذا كان نطاق المدرسة/الجامعة (Google Workspace Domain) مقفلاً حصراً على أعضاء المؤسسة، سيتطلب ذلك تسجيل الدخول المسبق ببريد المؤسسة.
- **إشعار المعلم**: البوت يضغط "طلب الانضمام" (Ask to join)، ويبقى في وضع الانتظار حتى يقبل المعلم طلب الدخول.
